# Veterinaria Pet It — Landing Page

Landing page SPA con SSR usando Next.js (App Router), React 19 y Tailwind CSS v4.

Ver `docs/ARQUITECTURA.md` para la documentación completa de arquitectura y convenciones, y `docs/CVE-2025-55182-NETLIFY.md` para el requisito de versión mínima de Next.js antes de despliegues.

## Tech Stack

- Next.js 15.x (App Router) — Server Components por defecto
- React 19
- Tailwind CSS v4 (`@theme`, sin `tailwind.config.js`)
- JSX plano (sin TypeScript)

## Getting Started

```bash
npm install
npm run dev      # desarrollo local (localhost:3000)
npm run build    # build de producción
npm run start    # servir build de producción
```
